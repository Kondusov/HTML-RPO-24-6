Сверстайте две страницы (Главная, контакты).
На обеих страницах навигационное меню (перелинковка между этими
страницами).
На главной:
- заголовок
- три параграфа с текстом (сгруппированы в одном родительском элементе).
- два изображения (1 подключено локально, второе с внешнего ресурса).
- далее два списка (упорядоченный и неупорядоченный).
- в подвале любой текст, с явным указанием мест переноса строк.

На странице контакты:
Сверстайте HTML форму.
Используйте в форме поля (input):
- текст
- число
- имейл
- пароль
- дата
- время
- цвет
- файл
- чекбокс
- радиокнопки
- select
- кнопка отправки формы
- кнопка сброса

Используйте изученные на уроке атрибуты для input.
